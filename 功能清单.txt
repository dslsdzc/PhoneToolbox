--- MTK BROM 直刷 (自研, 协议对照 mtkclient 源码逐条核实) ---
[√] BROM USB 枚举 + 握手 (A0 0A 50 05 回显补码, 3 次重试)
[√] BROM 命令层: SEND_DA / JUMP_DA / JUMP_DA64 / GET_TARGET_CONFIG
[√] BROM 内存协议: READ32/WRITE32 (echo 模式 + 状态字)
[√] DA 存储命令层: EMMC 读写 / PMT 分区表 (0x60/0x58/0x4C 三种条目)
[√] SEND_DA 上传 (16-bit XOR 校验 + 分块 + ZLP) + 跳转 DA
[√] SBC 修补 (preloader 字节模式, 参照 mtkclient 五模式)
[√] 刷写路由骨架 (runBromFlash: 枚举 → 会话 → 逐分区)
[√] DA 文件解析与选择: AllInOne 头/条目/region 5 字段 (真样本 6 文件 161 条目硬断言 + 独立 Python 解析器对拍)
[√] DA 两阶段: DA1 (region[1] 地址/长度/签名长度) → 0xC0 就绪 → 存储信息交换 → EMI/DRAM → DA2 (保留尾部签名) → read_flash_info
[√] EMI/DRAM 初始化: LEGACY 逐版本档位 (0x00/0x0A/0x0B/0x0C/0x0D/0x0F/0x10/0x11/0x14/0x15) + M_EXT_RAM_* 回包判定
[√] preloader 两路径: 显式指定 / 固件目录自动导入 (唯一命中才用) / 网络获取 (**默认关闭**, 来源清单 + sha256 校验, fail-closed)
[√] 刷写计划: 镜像 ↔ 分区匹配 (精确/前缀 preloader) + 大小校验 (镜像 > 分区 = 跳过不写) + 预览 (复用通用预览控件)
[√] 逐分区写入 + FINISH (0xD9) 收尾; 失败即停、不复位
[√] 代际判定: 内置芯片表 (转写自 bkerler/mtkclient, GPL-3.0, 89 条全表); 表外/IoT → 明确报错
[√] 三代路由 (D2/D3): 芯片表 damode + DA 文件 v6 (v6 强制 XML) → LEGACY / XFLASH / XML 三条链自动分派
[√] 诚实边界: SLA/DAA 检测返回明确错误 (RSA 响应生成标后续)

--- MTK BROM XFlash/XML 两代 (Phase D2+D3, 2026-09-16, 进行中) ---
[√] XFlash 帧层: 12B 小端帧 (magic/datatype/len, 头一次写+载荷分块) + status 三态判据 + ack 的 0x6781 特例 (16B 单写)
[√] XFlash 引导: 七步握手 (SYNC → SETUP_ENV → SETUP_HW_INIT → 读回 SYNC; **SYNC 只发不读**) + bring-up 四步 (expire_date/reset_key/checksum_level/connection_agent; 有回包的查询都带**尾部 status**, 分区表类别是唯一例外)
[√] XFlash EMI: INIT_EXT_RAM + **长度单独一帧** + 0x200 分块 (整块切片 912B, 与 LEGACY 800B 并存; 832 真样本两代对拍 832/832)
[√] XFlash DA2: BOOT_TO **剥尾部签名** + sleep + status ∈ {0, SYNC} —— 成功 = 状态字匹配, **不证明 DA2 在跑** (日志只写"已上传")
[√] XFlash 写读: WRITE_DATA **56B 参数** (8×u32 NandExtension) + write_packet_length 分块 (非 512 对齐 → fail-closed) + 循环后最终 status + CC_OPTIONAL_DOWNLOAD_ACT; READ_DATA 逐帧收数 + flag 判定
[√] GPT 分区表: 512/4096 扇区探测 + 头/条目**双 CRC fail-closed** + 备份 GPT 窗口兜底 (真 4096 样本 PGPT/SGPT + sgdisk 独立对拍; 上游 4 处缺陷不复刻)
[√] XFlash 链整合: GET_PACKET_LENGTH/GET_CHIP_ID/GET_PARTITION_CATA → GPT 读 → 逐分区 WRITE_DATA (地址取分区条目 first_lba) → SHUTDOWN 收尾; PMT 分支**明确拒绝** (上游不可达且有 bug)
[√] XML 帧层: 文本帧 (str 长度 = 字符数+1 且带 NUL) + OK / OK@0x<hexlen> / OK!EOT 保活 + command_result 解析 + DA 日志帧**跳过** (有上限) + `ERR!` 一律判失败 (不复刻上游把它当成功)
[√] XML 引导: 等 **CMD:START** 文本消息 + setup_env (`initialize_dram=YES`, **不发 EMI**) / setup_hw_init / SET-HOST-INFO; 三步各自点名失败
[√] XML 写读: WRITE-FLASH (FileSysOp key=FILE-SIZE → ackValue(length) ×2 → 逐包 ack/数据) / READ-FLASH (**逐帧 ack** 的 download_raw 形状, 独立于单次尾 ack 分支) / REBOOT 收尾
[ ] XML 链整合 (进行中)
[ ] 刷机通道文案 (说明走了哪条链) + 文档收口 (进行中)
[√] 诚实边界: **真机全链未验证 (三代都没有)**; XML 侧**无真实设备样本** (帧与命令全部来自上游代码); GPT 样本来自第三方仓库 (MPL-2.0, 只读离线、不进构建); XFlash/XML 都只走**主 GPT** (diskSectors=0, 备份兜底不可用且如实说明); 存储暂只 eMMC user (0x1/0x8)
